Run these for performance metrics. Each uses MCP mode (the path opencode uses), --insecure for the internal HPE CA, and saves JSON.

1. Multimodal dataset — andrew-bydlon-test-dataset (664 docs), no reranker:
python3 tests/benchmark.py --mode mcp \
  --url https://rag-mcp-server.pcai-se-ai-application.hst.rdlabs.hpecorp.net/mcp \
  --api-url https://rag-mcp-server.pcai-se-ai-application.hst.rdlabs.hpecorp.net \
  --dataset andrew-bydlon-test-dataset \
  --N 20 --duration 30 --ramp-up 5 --top-k 10 --insecure \
  --output tests/benchmark_results/mm_no_reranker.json

2. Multimodal dataset — with reranker (measures cross-encoder latency cost):
python3 tests/benchmark.py --mode mcp \
  --url https://rag-mcp-server.pcai-se-ai-application.hst.rdlabs.hpecorp.net/mcp \
  --api-url https://rag-mcp-server.pcai-se-ai-application.hst.rdlabs.hpecorp.net \
  --dataset andrew-bydlon-test-dataset \
  --N 20 --duration 30 --ramp-up 5 --top-k 10 --use-reranker --reranker-top-k 5 --insecure \
  --output tests/benchmark_results/mm_reranker.json

3. Text-only dataset — stack-project (10,500 docs), no reranker:
python3 tests/benchmark.py --mode mcp \
  --url https://rag-mcp-server.pcai-se-ai-application.hst.rdlabs.hpecorp.net/mcp \

4. Text-only dataset — with reranker:
python3 tests/benchmark.py --mode mcp \
  --url https://rag-mcp-server.pcai-se-ai-application.hst.rdlabs.hpecorp.net/mcp \
  --api-url https://rag-mcp-server.pcai-se-ai-application.hst.rdlabs.hpecorp.net \

Notes:
- I confirmed the dataset names via the MCP server: the text-only one is stack-project (you wrote stacks-project).
- --api-url is required because the script otherwise derives host:8000, which this external virtual service doesn't expose.
- Tune --N (concurrency) and --duration up for steadier percentiles — e.g. --N 50 --duration 60 for a heavier load run.
- Pre-existing caveat: in MCP mode the script records avg_results/query as 1 (it can't parse result counts from MCP text content), so rely on req/s and latency percentiles for comparison.
