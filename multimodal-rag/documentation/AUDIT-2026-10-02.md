## P0 — fix before next deployment

### P0-1 · Self-selection is an ACL bypass (verified by subagent EXECUTION + lead reproduction)
`access_store.verify_and_select` (access_store.py:468–493) demands a password **only** when `has_password(ds)`; `select_dataset` (:310+) checks only the denylist. **`is_public_dataset()` is enforced nowhere in the selection path** (grep: catalog listing only, api_server.py:2338/2366). So any registry/JWT identity can self-select any **unowned, password-less** dataset — the default state for most datasets — and then read/write it via all ACL-guarded tools (search, files, add/delete/replace docs, memory). Repro: `alice` (ACL={alice-mem}) denied `search_dataset("bob-private")` → `select_dataset("bob-private")` succeeds → full access. Same helper serves REST (`/api/datasets/{name}/select`, api_server.py:1806) and D21 JWT users (zero datasets by design → all can self-select).
The module docstring (access_store.py:5) and access.html:678-681 both state the intended rule the code doesn't enforce.
**Fix:** in `verify_and_select`/`select_dataset` require `has_password(ds) or operator_allows(identity, ds) or is_public_dataset(ds)`; add a test asserting `dataset_allowed(alice, "bob-private") is False` after a select attempt.

### P0-2 · Arbitrary local-file read via the embedder's media-fetch path (lead-verified)
`_check_media_url_policy` (url_policy.py:163–164) **returns immediately for non-http URLs**, and `model_adapters.py` never calls `_media_path_allowed` (0 hits). `_fetch_obj_async` (:567+) does `url.removeprefix("file://")` → `open(url, "rb")` — subagent executed a read of a victim dataset's file through it. Reachable from `search_dataset/search_datasets/search_memory` via caller-supplied `image=/video=/audio=` (mcp_server.py:2995-2997, 3129-3131, 3398-3400) — the embedder loads the "media". Default prefix `{DATA_PATH}/datasets` means one admitted key + knowing one dataset name reads any other dataset's raw files (including uuid-prefixed originals that `api_serve_file`'s regex deliberately filters). The rest of the codebase enforces the allowlist (rag_system.py:742/766/2065 raise `MediaRefError`) — this is the one missed site. Related: `dataset_add_documents` validates `paths` but not `texts` dicts (reaches `_validate_document_media_refs` as a media ref).
**Fix:** enforce `_media_path_allowed` in `InputConversion._fetch_obj_async`/`_fetch_video_frames`/sync twin (fail-closed) and reject `file://`/bare paths at `_check_media_url_policy`; validate `texts` like `paths`.

## P2 — medium (condensed)

- **Identity:** JWT verification on the event loop + forced JWKS refetch per unknown `kid` → unauthenticated DoS when OIDC is on (oidc_identity.py:453-457); password throttle is per-process (16 buckets on scale) — move to Redis; ≤30 s `has_password` stale-negative bypass window on reads (fix exists — `has_password_fresh` — used only for imports); `?password=` query-param channel on 4 endpoints contradicts the repo's own rule; media/file serving has no D15 ACL check (password/token = capability); `ttl=0` unlocks store plaintext passwords in Redis indefinitely; Set-Cookie value injection via SSO `next` (`;`-smuggling re-scopes the state cookie cross-domain).
- **Local creds (corrected severity):** 10 live bearer JWTs in gitignored `utils/pcai_models.py` (untracked; **NOT** in shipped tarballs — both verified) + TLS `verify=False` default for remote model endpoints → rotate tokens, set `REMOTE_CA_BUNDLE` (fail-closed in production).
- **Processors:** `.tar.gz` skips the entries audit at layer 1 (**not** the claimed 100 GB bomb — `_extract` routes all double-extension tars through the capped streamed decompress + nested re-audit; worst-case transient ≈ 2×2 GiB); no per-file processing deadline (100k-page PDF / 10 h video park an ingest worker); PIL bombs rely on stock defaults (no `MAX_IMAGE_PIXELS`); RAR size enforcement post-extraction; `/batch-files` unbounded count; YAML alias-DAG → flattener explosion (11.1M keys in 7.5 s, no node budget).
- **Data core:** ETag-absent sync skips on size alone (`None == None`); `_flush_hash_index_writes` not in `finally`; `_read_meta` swallows parse errors with no log (silent dataset disappearance); orphan twins survive ID deletes; BM25 df-stats rewritten per file during batch ingest (O(N×vocab) NFS writes).
- **MCP:** `_validate_dataset_name` never called in mcp_server (`dataset_name="../../datasets/<other>"` reaches `_dataset_dir`); `_resolve_memory_dataset` honors a caller-supplied `dataset_name` argument over the ★ header binding (prompt-injection vector); memory lifecycle keyed on session_id not identity (cross-user session-history deletion when a dataset is shared); password-protection state enumerable via the "is password protected" vs "Incorrect password" distinction; `RAG_ACCESS_STORE=0` disarms the fail-closed anonymous branch (scale-chart values still document `accessStore: false` as the default); `mcp_auth_warn_if_open()` discards the shared verdict and returns only the OIDC half, so "auth is open" cannot be programmatically detected; SSE/streamable-http auth gates rely on `add_middleware` ordering (a first-request-only 401 was observed — wrap the app structurally instead).
- **Deployment:** AuthorizationPolicy gates only the edge — MCP :9090, /metrics, Qdrant (no `QDRANT__SERVICE__API_KEY`), Redis (empty password) all open east-west; NetworkPolicy ships only in base chart; no preStop/terminationGracePeriod for long ingests (30 s default vs 3600 s uploads); supply chain: no digest pins, `openai` unbounded, qdrant runs as root, no seccompProfile (offset by excellent baseline hardening: uid 1000, RO rootfs, caps dropped, no token automount anywhere); NOTES.txt:25-26 tells operators /mcp "runs OPEN" — the wiring is the OPPOSITE (the MCP container inherits the REST admin key via envFrom and `admin_keys()` treats it as admin), so the post-install guidance is wrong in the dangerous direction.

## Performance top-5 quick wins (DeepSeek-core, all low-risk)

1. **`_read_meta` mtime cache** (~15 lines) — removes 2 NFS syscalls + JSON parse per search and per federated target; the hottest endpoint.
2. **Move the MCP throttle into `_check_unlocked_or_password`** (~5 lines) — closes P1-7.
3. **Exclude `metadata.image`/`video` from sync scrolls** (1 line each) — stops multi-MB base64 transfers per point per reconcile tick.
4. **`_store_file`: `.part` sibling + `os.replace`** (~6 lines) — eliminates torn originals that get re-embedded as garbage (closes P1 in C4).
5. **Defer BM25 df-stats + `.ingested_hashes.json` to once per batch** (~40 lines) — kills the O(N×vocab) NFS write pattern on bulk ingest.

Next tier: bound federated fan-out (semaphore + per-dataset `wait_for` + default Qdrant client timeout in the base chart), `set_password` lock, JSON body-cap middleware.

## What's solid (verified, keep)

- **SSRF defense:** single-resolution DNS pin (check-time = fetch-time), per-hop redirect re-validation everywhere, fail-closed unresolved hosts, dedicated 411-line test suite.
- **Crypto discipline:** RS256-only JWT (none/HS rejected), constant-time compares throughout, keys `token_urlsafe` + shown-once + masked everywhere, PBKDF2-600k, constant-time SSO state check.
- **D15–D25 plumbing** largely matches its tests: fail-closed D20, D19 delegation can't escalate, D21 JWT-never-admin, D23 ownership-before-password, D25 self-mint refuses keys.
- **MCP async hygiene:** `_offload` copies contextvars (no wider-identity fallback), header middleware textbook token/finally, all caches LRU-bounded, hard Qdrant filter construction (no injection).
- **Deployment baseline:** uid-1000 + RO-rootfs + caps-dropped + no-automount everywhere, full probe trio on both containers, zero key material in the delivery path (verified into the tarballs), real ROTATION.md, calibrated HPA with documented rationale.
